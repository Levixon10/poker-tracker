# Poker Chip Tracker

Offline poker chip/pot tracker for home games. Track blinds, bets, raises, calls, folds, all-ins, side pots, split pots, buy-ins and end-of-night settlement.

**Play:** https://levixon10.github.io/poker-tracker/

Works offline after the first visit — add it to your home screen to use it like an app. All data is stored locally on your device.
